# Blogger Studio — لوحة تحكم المدونين

مشروع مستقل لبناء لوحة إدارة تدوين عربية RTL مستوحاة من خصائص Blogger.

## المزايا المخططة
- لوحة إحصاءات ومركز نشاط
- إدارة المقالات: مسودة، مراجعة، مجدول، منشور، مؤرشف
- محرر محتوى وتصنيفات ووسوم ووسائط
- تعليقات ومراجعة الرسائل المزعجة
- SEO لكل مقال: slug، وصف، canonical، OG، schema
- إدارة الصفحات والقوائم والروابط وإعادة التوجيه
- إعدادات المدونة والخصوصية والكوكيز
- أدوات فحص SEO وrobots.txt وsitemap.xml
- دعم تعدد المدونات والصلاحيات

## التقنية
- Frontend: HTML/CSS/JavaScript RTL
- Backend: Supabase Auth + PostgreSQL + Storage
- Security: Row Level Security على كل بيانات المستخدم
- Hosting: GitHub Pages للواجهة التجريبية أو استضافة تدعم بيئة الإنتاج

## قاعدة البيانات
سيضاف مخطط SQL جديد ضمن `supabase/migrations/` بعد اختيار المستودع المستهدف وتأكيد إنشاء مشروع Supabase. لن يحتوي المتصفح على Service Role key.

## الحالة
هذه وثيقة المخطط الأولي فقط؛ لم يتم إنشاء قاعدة بيانات أو تطبيق إنتاجي بعد.
